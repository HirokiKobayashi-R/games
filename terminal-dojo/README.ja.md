# Terminal Dojo

**誘って、避けて、隙に一撃。** ターミナルで遊ぶオリジナルのCPU対戦ゲームです。
Python標準ライブラリだけで動きます。既存ゲームのキャラ・画像・音声は使用していません。

## 起動

このディレクトリで:

```sh
./Play.command
```

このフォルダで実行してください。
Mac以外のPOSIX端末やPythonから直接起動する場合:

```sh
python3 dojo.py
```

Python 3.9以降とcurses対応端末が必要です。追加パッケージ不要。
推奨80列×24行、最低64列×22行。IMEは英数モードにしてください。
MacではFinderから`Play.command`をダブルクリックする方法もありますが、GUI起動は自動検証していません。

## 最初の勝ち方

1. Enterで開始。CPUが近づくのを待つ。
2. **CPU WINDUP 3→2→1**が見えたら、**Aで一歩下がる**。壁際ならWで跳ぶ。
3. 空振りして**OPEN!**になったら、**Dで戻ってJ**。
4. **PUNISH! -32**が成功の合図。火花・短い停止・ノックバックが入り、4回のきれいな反撃でKO。

CPUは構えた位置から攻撃し、構え中は追いかけてきません。通常の接近では、一歩下がれば避けられる距離を保ちます。
自分から密着すると一歩だけでは射程外に出られないので、早めに距離を取るかジャンプを使ってください。
CPUの構えを連打で止めることはできません。通常攻撃は8ダメージ、CPUの攻撃は22ダメージなので、正面での連打は不利です。
ガードは2ダメージに軽減しますが、空振り後の反撃ボーナスは作れません。

## 操作

| キー | 操作 |
| --- | --- |
| Enter / Space | 開始 |
| A / D、← / → | 左右に短く移動 |
| W / Space / ↑ | ジャンプ |
| J | 攻撃 |
| K | 0.65秒ガード。再入力で延長 |
| P / Esc | 一時停止 |
| P / Enter | 停止中に再開 |
| R | 停止中・決着後に再戦。決着後はEnterでも可 |
| V | DOT表示 / ASCII表示を切り替え |
| Q / Ctrl-C / Ctrl-D | いつでも終了 |
| Ctrl-Z | 一時停止（OSのジョブ停止はしない） |

100HP、25秒ラウンド。0HPでKO、時間切れは残HPが多い方が勝ち。同値や同時KOは引き分けです。
攻撃中・攻撃後の硬直は移動やガードでキャンセルできません。被弾直後も短い硬直があります。

## 駆け引きの時間

| 動作 | 時間 / ダメージ |
| --- | --- |
| CPUの予備動作 | 0.48秒。足を止めて構える |
| CPUの空振りの隙 | 0.95秒。OPEN中の一撃だけ32ダメージ |
| CPUが当てた・ガードされた後の硬直 | 0.55秒。反撃ボーナスなし |
| プレイヤーの攻撃 | 予備動作0.12秒 + 硬直0.38秒 |
| 通常ヒット / ガード時の停止演出 | 0.065秒 / 0.025秒 |

命中時の停止演出はキャラだけを止め、25秒の時計は実時間で進みます。
OPEN中のボーナスは1回のみで、同じ空振りへ連続でボーナスを重ねることはできません。

## 描画と端末の制約

60Hzを目標に描画します。DOT表示は1文字を横2×縦4の点で扱い、キャラが横半文字・縦1/4行ずつ動きます。
同じ80列・同じ移動速度で、位置が変わる回数はASCIIの21回/秒に対して44回/秒、ジャンプは5段階に対して17段階です。
これは出力文字の中間位置を数えた結果であり、物理ディスプレイのFPSの測定ではありません。

点字をエンコードできない・curses上で1列幅にならない場合はASCIIへ自動で切り替えます。
実フォントが欠ける、点が見づらい場合はVでASCIIへ戻してください。フォント・アプリ・セキュリティ設定は変更しません。

通常のターミナルにはキーを離した通知や正確な同時押し状態がありません。
移動は1入力につき0.16秒、ガードは0.65秒。キーリピートでも操作できますが、初動後の待ち時間はOS・端末に依存します。
まず短いタップで遊んでください。複雑なコマンド技はありません。

## 停止・終了

リサイズ、最低サイズ未満、0.5秒以上の処理停止を検出すると対戦を停止します。サイズを戻してPで再開。
通常終了、Ctrl-C、SIGINT、SIGTERM、SIGHUPでは端末設定と元の画面を復元します。
SIGKILLや端末のクラッシュで復元処理を実行できなかった場合は端末で`reset`を実行してください。
非TTY入力と`TERM=dumb`は説明付きで拒否します。

## 開発・検証

- `combat.py`: 時間・衝突・AI・予告/回復状態・勝敗。
- `sprites.py`: 2×4点の描画。ゲーム状態は変更しない。
- `dojo.py`: 入力・描画・停止・端末復元。
- `tests/`: 標準unittestと実PTY。

```sh
python3 -m unittest discover -s tests -v
```

テストには実時間25秒の対戦が含まれるため、全体で約1分かかります。
20個の固定乱数seedで「120ms反応して回避→反撃」が勝ち、単純連打は負けることを確認します。
PTYでは画面の予告を読み、A→D→Jの実キー入力で4回反撃してKOする経路、CPU勝利、時間切れ、再戦、リサイズ、中断、終了時復元を検証します。
macOSの一時状態フラグPENDINを除き、端末の永続フラグ・速度・制御文字は起動前との一致を検査します。

macOS 26.6.1 / Python 3.12.8で検証。Terminal GUI操作は使用していません。
実キーボードの感触、モニター上の滑らかさ、別端末・別OSでの互換性、楽しさそのものは人によるプレイ確認が必要です。
通信・オンライン対戦・Codex lifecycleフック・保存データ・追加インストールはありません。Codex Actionは独立起動のみです。起動テストは画面を待ち、150msでの起動完了を仮定しません。
